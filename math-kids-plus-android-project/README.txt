MATH KIDS PLUS - Android build kit

1. Make a free account at github.com and create a new repository (name it math-kids-plus).
2. Upload everything from this folder to it (Add file > Upload files).
   IMPORTANT: check that the folder ".github/workflows" was uploaded. If not, click
   Add file > Create new file, type  .github/workflows/build-android.yml  as the name,
   and paste the text from build-android.yml.txt.
3. Open the "Actions" tab. Click "Build Android APK and AAB" > Run workflow.
4. Wait about 5-10 minutes. Open the finished run and download "math-kids-plus-android" at the bottom.
5. Inside: math-kids-plus.apk (install on a phone), math-kids-plus.aab (for Google Play),
   upload.jks + KEEP-THIS-password.txt (your signing key: SAVE THESE SAFELY, you need them for every update).
